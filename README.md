# Minecraft World Tour · Web

Página de presentación en español del proyecto https://github.com/gastonheinz/minecraftworldtour.

## Abrir

Abrí `index.html` en tu navegador o ejecutá desde esta carpeta:

```powershell
python -m http.server 4173
```

Luego visitá http://localhost:4173.

Sitio estático sin compilación ni dependencias. Puede publicarse en GitHub Pages, Netlify o cualquier alojamiento estático.

La vista interactiva es una ilustración procedural, no una captura de mundos generados ni una herramienta de generación. Los destinos cambian la ilustración. El generador real se ejecuta desde el proyecto Rust enlazado. Los contenidos se basan en el README y documentación local del proyecto al 29/09/2026.

Los archivos `index.html`, `style.css` y `app.js` contienen el contenido, diseño e interacciones. Las fuentes de Google Fonts son opcionales y tienen fuentes locales de respaldo.
